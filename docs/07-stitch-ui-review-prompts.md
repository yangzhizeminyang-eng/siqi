# Stitch UI 评审与二次优化提示词

## 1. 评审结论

本次 Stitch 生成的 UI 已经具备企业研发控制台的基础样子，工作台、任务列表、创建任务、任务详情、审批中心、任务回放、Diff 审核、索引管理和项目配置等核心页面基本覆盖。

但当前版本还不适合直接作为最终高保真稿，主要问题集中在：

- 产品命名不统一；
- 导航体系在不同页面不一致；
- 部分页面仍出现英文或旧文案；
- 一些按钮和表格文字发生换行、截断；
- Diff 审核页偏离主系统 App Shell；
- 索引管理和项目配置页面细节还不够完整。

建议以 `stitch_ai_agent.zip` 中 15 页版本为主，`stitch_ai_agent (1).zip` 中 5 页版本只作为参考。

## 2. 全局问题

| 问题 | 影响 | 优化方向 |
| --- | --- | --- |
| 产品名混乱 | 出现“AI 研发协作平台”“企业级AI助手”“DevOps 差异评审”等不同名称 | 统一为“司契（Siqi）” |
| 版本文案混乱 | 出现 `Enterprise Edition`、`v2.4.0` 等不属于 MVP 的文案 | MVP 阶段不展示企业版版本号 |
| 导航不统一 | 有些页面用“仪表盘 / 项目设置 / 差异审计” | 统一为“工作台 / 项目配置 / Diff 审核” |
| 部分按钮文字换行 | “提交审阅意见”“重建索引”等按钮显示不完整 | 增加按钮最小宽度，禁止按钮文字换行 |
| 表格列过窄 | 任务列表、索引管理中字段被拆行 | 设置关键列最小宽度，长文本省略并支持悬浮提示 |
| 英文表头残留 | 任务回放里有 Query、Summary、Source File、Score 等英文 | 除代码、路径、Commit SHA 外，界面文案全部中文 |
| 模拟数据日期过旧 | 页面里出现 2023 年数据 | 改为 2026 年演示数据或使用“刚刚 / 10 分钟前” |


## 14. 全局优化后复审结论（stitch_ai_agent (4).zip）

### 14.1 本轮已经改善的内容

本轮生成结果相较之前已经有明显进步：

- 已补齐创建任务、索引管理、审批中心和 Diff 审核等核心页面；
- 页面整体开始使用统一的左侧导航和企业研发控制台布局；
- 审批中心已经体现高风险强提示；
- 任务详情已经包含问题确认、修改计划、检索上下文和审批记录；
- 索引管理已经包含索引状态、Commit SHA、文件数、切片数和详情抽屉；
- Diff 页面已经包含文件列表、左右代码对比和审阅意见输入框；
- 整体视觉风格符合 MVP 阶段的克制、清晰、技术型定位。

### 14.2 仍需修正的问题

当前版本还不建议直接作为最终高保真稿，剩余问题主要是视觉收口和文案一致性：

1. 多个页面左上角仍显示 `Enterprise Edition`，MVP 阶段应删除。
2. `项目设置`、`项目配置` 两种名称仍同时出现，必须统一为“项目配置”。
3. 任务列表筛选器出现“所有项目 (All Projects)”中英混排，界面文案应统一中文。
4. 创建任务页仍显示 `Issue ID`，建议改为“Issue 编号”。
5. 任务列表中的“等待人工审批”状态标签过窄，存在拥挤或换行风险。
6. 风险等级有时显示为“高 / 中 / 低”，应统一显示“高风险 / 中风险 / 低风险”。
7. 任务详情页右上角操作按钮存在“审批 / 执...”被截断的问题，应改成“打开审批”并保证不换行。
8. 任务详情页的问题确认区只有“提交回答”，还应提供“跳过问题”和“重新生成计划”。
9. 任务详情页的检索上下文缺少行号和 Commit SHA，无法完整满足 RAG 来源追溯要求。
10. 任务回放页仍存在 `Source File`、`Lines`、`Summary`、`Query`、`Score` 等英文表头。
11. 任务回放页还需要明确展示重试、取消、测试执行、PR 描述生成和演示兜底标记。
12. 索引管理页部分字段显示过窄，尤其是“切片数”、状态和失败原因。
13. 项目配置页仍有 `Repository URL`、`Default Branch` 等英文辅助文案，建议改成中文。
14. Diff 审核页没有完全使用统一的左侧 App Shell，当前仍更像独立页面。
15. Diff 审核页“提交审阅意见”按钮发生换行，必须固定最小宽度。
16. Diff 审核页需要明确标识“演示兜底”产物，避免用户误以为是真实执行结果。
17. `DESIGN.md` 的品牌名仍为 `DevOps Sentinel`，应同步改为“司契（Siqi）”。
