# 企业版部署架构与运维文档

> ⚠️ **历史兼容入口（已冻结）**：本文是企业版早期草稿，内容已被 `docs/enterprise/08-deployment-ops.md` 取代。
> **请以 `enterprise/` 目录为准**，本文仅保留用于追溯早期设计决策，不再更新。
> 已知过时点：§3 的 `8003` 是早期规划端口，**实际落地为 `8081`**（公网 80→308→443 经宿主机 Nginx 回代 `127.0.0.1:8081`）。

## 1. 文档定位

本文档面向企业版私有化部署、运维、监控、备份和升级。

> **权威文档**：`docs/enterprise/08-deployment-ops.md`

## 2. 部署形态

| 形态 | 说明 | 适用阶段 |
| --- | --- | --- |
| 单机 Docker Compose | 所有服务部署在一台云服务器 | MVP、团队版、小规模企业试点 |
| 分离式部署 | 应用、数据库、Redis、Milvus 分开部署 | 企业版推荐 |
| 内网私有化 | 不暴露公网，只在企业内网访问 | 企业正式交付 |

## 3. 企业版公网入口

> **早期规划值为 `8003`，已作废。** 实际落地如下（见 `docs/enterprise/08-deployment-ops.md`）。

| 环境 | 实际入口 |
| --- | --- |
| 团队版 | `http://<server-ip>:8080` |
| 企业版（无域名阶段） | `http://<server-ip>:8081`（默认来自 `${ENTERPRISE_PUBLIC_PORT:-8081}`） |
| 企业版（生产，已落地） | 宿主机 Nginx `80 → 308 → 443`，回代 `127.0.0.1:8081`；公网 8081 已收敛关闭 |

正式域名入口：

```text
https://agentforge.ltd
```

## 4. 企业版组件

| 组件 | 企业版要求 |
| --- | --- |
| 前端 | 支持独立构建和企业配置 |
| 后端 | 支持 `APP_ENV=enterprise` |
| MySQL | 独立实例或独立库 |
| Redis | 独立实例或独立 DB |
| Milvus | 独立 Collection 或独立实例 |
| Nginx | 统一入口、反向代理、上传限制、超时配置 |
| 日志 | 结构化输出，支持采集 |

## 5. 监控指标

- API 错误率。
- API 响应时间。
- Celery 队列积压。
- Agent 任务失败率。
- Embedding 失败率。
- Milvus 检索耗时。
- MySQL 慢查询。
- Redis 连接状态。

## 6. 备份恢复

| 对象 | 策略 |
| --- | --- |
| MySQL | 每日备份，保留 7 到 30 天 |
| Milvus | 定期快照或按 Collection 备份 |
| 配置文件 | 每次发布前备份 |
| 审计日志 | 独立归档 |

## 7. 升级与回滚

- 发布前记录当前版本号和镜像号。
- 发布前备份数据库。
- 发布后执行健康检查。
- 失败时回滚镜像和配置。
- 数据库迁移必须可追溯。

## 8. 验收标准

- 企业版可通过独立端口启动。
- 关键组件健康状态可检查。
- 数据备份可恢复到测试环境。
- 发布失败有回滚路径。
