## 2. 名称释义与出处

- **司**：执掌、主管。古语「有司」即主管部门；「司契」即掌管契据之人。
- **契**：契据、符契、券书。「符契」古时一分为二、双方各执一半，合而验真才生效——恰好对应本项目的「人工审批门禁」：合契才可落章。
- **出处**：《道德经》第七十九章：「是以圣人执左契，而不责于人。有德司契，无德司彻。」——执契存证而不苛责于人，即「可审计、可追责，但不以工具苛待人」的产品哲学底色。

### 品牌故事（四段式，与主链路一一对应）

| 环节 | 品牌叙事 | 产品链路 |
| --- | --- | --- |
| 拟契 | Agent 拟一份待批的契 | AI 分析 → RAG 检索 → 结构化修改计划 |
| 成契 | 人落章，契始成 | 人工审批通过 / 风险调整 / 重写 |
| 存契 | 每一步都留底 | Diff、测试结果、事件与审计日志持久化 |
| 复契 | 以旧契证新事 | 任务回放、历史复用摘要、相似任务参考 |

*符号方向（可选延展）：以「合契」——左右半符相合——为视觉符号原型，尚待设计，未实施。*

## 3. 标语体系

- **主标语（推荐）**：执契不苛，落笔有据。
- 备选：
  1. 事事有契，全局可复。
  2. 拟契在机，成契在人。
- 使用规范：主标语用于 README、登录页等第一联系人；备选可用于分页面或阶段材料；同屏不叠用两条标语。

## 4. 使用规范（文档 / UI / 代码）

- **文档**：首次出现写「司契（Siqi）」，其后可简称「司契」。
- **UI**：中文环境显示「司契 Siqi」；英文环境显示「Siqi」（AppShell 双语逻辑沿用）。
- **代码与资源**：API title 用 `Siqi API · Enterprise AI Agent R&D Collaboration Platform`；截图与资产文件名前缀 `siqi-`。
- **域名**：不绑定品牌，沿用 `agentforge.ltd`（URL 与品牌名可不一致，属常态发布实践）；如需品牌入口可考虑子路径或可选子域。

### 6.4 操作步骤（Checklist）

- [ ] 登录中国商标网 → 近似查询：按 6.2 逐词检索第 9 / 42 类
- [ ] 记录命中：申请人、申请号、状态（已注册 / 等待实质审查 / 初审公告 / 无效 / 驳回）、类别、商品项
- [ ] 近似初判：同音、近形或含义近似 + 同类商品 → 高风险；跨类或显著性差异明显 → 中低风险
- [ ] 补充抽查：第 35 类（广告销售 / 商业管理）等防御性类别
- [ ] 结论输出：无冲突 → 尽早在官网提交（申请在先原则）；有冲突 → 评估共存、绕行（如「司契云」等组合标）或委托代理
- [ ] （可选）委托代理机构出具正式《商标查询报告》

### 6.5 提交与流程要点

- **材料**：主体资格证明（营业执照）、商标图样（中文建议普通印刷体 / 黑体，避免需授权的商业字体）、类别与商品项。
- **官费参考**：网上申请每类 270 元（含 10 个商品 / 服务项目，超项另计），以中国商标网公告为准。
- **流程**：提交 → 形式审查 → 实质审查 → 初审公告（3 个月异议期）→ 注册公告并发证（整体周期一般为数月至一年，以实际审查进度为准）。
- **策略建议**：预算允许时，中文「司契」与英文「SIQI」分开申请，权利覆盖更稳。

- 「契」为常用字，检索时务必覆盖同音字组合（6.2 第 3、4 项）。
- 域名与品牌解耦：`siqi.com / .cn / .ai` 等短域名已被注册属正常现象，不影响商标申请与产品发布。
